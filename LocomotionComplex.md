# LocomotionComplex (Rocodromo)

Para realizar el ejercicio hice una copia del **Wall** que sale en el ejemplo el 
cual modifique su tamañdo para hacerlo mas alto y le añadi 2 **HandleSet** a mayores,
en  el gameObject **Handles(Climbable)** dentro de las opciones que proporciona el script **Climb Interactable**
le añadi dentro del apartado del **ClimbProvider** que estaba vacio el Script con el mismo nombre **ClimbProvider** (no se si es correcto así),

Para el video fui controlando individualmente cada manda seleccionando Shift+G+Q para el mando izquierdo y G+Q para el derecho y así poder escalar el muro
(Entiendo que es así ya que en los apuntes menciona que durante la acción de escalar la gravedad se desactiva y cuando se deja esta se recupera haciendo que el
usuario vuelva al suelo, que es mas o menos lo que se muestra en el video)
